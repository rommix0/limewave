# Limewave v0.8: release checklist

Status key: **verified (how)**, **covered by automated test (name)**, or **NOT verified: needs a human (what to do)**.

This release adds the **Loop finder** panel beside the seam view and the `loop_lab` bench. The rows below are the manual checks that listening and looking can answer. None of them has been run by hand yet, so every row is **NOT verified** until you have tried it.

They use `81 Track81_008.wav` and `81 Track81_009.wav` (local only, never committed), any instrument you have, and `loop_lab` for the stored loop's measures. Run the app with `cargo run --release -p limewave`.

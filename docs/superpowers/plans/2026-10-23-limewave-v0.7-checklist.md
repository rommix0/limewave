# Limewave v0.7: release checklist

Status key: **verified (how)**, **covered by automated test (name)**, or **NOT verified: needs a human (what to do)**.

This release adds the **Waveform | Spectrogram** switch for the main view and **Effects > Repair click**. The rows below are the manual checks that listening and looking can answer. None of them has been run by hand yet, so every row is **NOT verified** until you have tried it.

They use `samples/RSB 501-01` (local only, never committed) and any other local samples you have, including a stereo file and a long one. Run the app with `cargo run --release -p limewave`.

## Manual checks

| # | Check | Status |
| --- | --- | --- |
| 1 | Repair a click in an RSB 501-01 sample and listen across it. | [ ] NOT verified: needs a human |
| 2 | Repair a 40 to 50 ms dropout in a sustained note and listen for dulling. | [ ] NOT verified: needs a human |
| 3 | Repair Left only on a stereo file with a one-sided click. | [ ] NOT verified: needs a human |
| 4 | Switch to Spectrogram on a 5-minute file. The window stays responsive, and the picture appears. | [ ] NOT verified: needs a human |
| 5 | Drag markers and make a selection in the Spectrogram view, then play the loop. | [ ] NOT verified: needs a human |
| 6 | Restart the app and check that the view choice is remembered. | [ ] NOT verified: needs a human |

# Limewave v0.6: release checklist

Status key: **verified (how)**, **covered by automated test (name)**, or **NOT verified: needs a human (what to do)**.

This release adds sample-rate conversion: **Effects > Change sample rate…**, its undo and redo, the saved file's rate, and the scaling of an instrument's frame opcodes. The rows below are the manual checks that listening and other programs can answer. None of them has been run by hand yet, so every row is **NOT verified** until you have tried it.

They use `samples/RSB 501-01` (local only, never committed), whose WAVs are mono at 30 kHz and 15 kHz. Run the app with `cargo run --release -p limewave`.

## Manual checks

| # | Check | Status |
| --- | --- | --- |
| 1 | Convert an RSB 501-01 sample to 44,100 Hz and listen for pitch and artefacts. | [ ] NOT verified: needs a human |
| 2 | Take a modern sample down to 13,000 Hz and listen for the darker sound with no aliasing whistle. | [ ] NOT verified: needs a human |
| 3 | Undo and redo across a conversion while a note plays. | [ ] NOT verified: needs a human |
| 4 | Save an instrument after converting one of its samples, reopen it, and check the loop and tuning. | [ ] NOT verified: needs a human |
| 5 | Type an odd rate (31,250) and check that the saved file reports it in another program's file info. | [ ] NOT verified: needs a human |
| 6 | Escape closes the Change sample rate dialog while the New rate field has focus. | [ ] NOT verified: needs a human |
| 7 | In an instrument, Change sample rate… converts the selected region's sample, and the region still plays in tune. | [ ] NOT verified: needs a human |
